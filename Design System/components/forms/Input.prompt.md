The standard text field, used across the reservation and contact forms.

```jsx
<Input id="name" label="Name" placeholder="Ihr Name" />
<Input id="mail" label="E-Mail" type="email" hint="für die Bestätigung" error="Bitte prüfen Sie die Adresse." />
```

Focus draws a clay border plus the focus ring; the label never floats or animates. `Label` is exported separately for custom controls.
