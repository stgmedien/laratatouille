The system's dividers — the main decorative device in an otherwise undecorated layout.

```jsx
<Rule variant="short" />        {/* 56×2 gilt bar under a section heading */}
<Rule variant="ornament" />     {/* hairline–diamond–hairline, ends a section */}
<Rule />                        {/* plain 1px linen hairline between rows */}
```

Use `ornament` sparingly: at most once per section, never twice in a row.
