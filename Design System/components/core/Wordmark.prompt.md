The brand mark: "La Ratatouille" in Marcellus with a gilt rule and small-caps tagline. Use this anywhere a logo would go — there is no logo file.

```jsx
<Wordmark size={20} subtitle="Sanet y Negrals" />
<Wordmark size={56} tone="inverse" />
```

`tone="inverse"` on pine or photography. Drop the subtitle (`showSubtitle={false}`) below ~18px, where the small caps stop being legible.
